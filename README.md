# 개인 블로그 서비스

Next.js 13로 개발된 개인 블로그 플랫폼입니다. MDX를 지원하여 마크다운으로 콘텐츠를 작성하고 React 18 컴포넌트를 활용할 수 있습니다.

## 주요 기능
- ✨ 마크다운(MDX) 지원 - 텍스트 콘텐츠와 React 컴포넌트를 함께 사용할 수 있습니다
- 🌓 라이트/다크 모드 - 사용자 환경에 맞게 테마를 변경할 수 있습니다
- 🏷️ 태그 시스템 - 콘텐츠를 카테고리별로 정리하고 필터링할 수 있습니다
- 📚 시리즈 그룹화 - 연관된 글을 시리즈로 묶어 관리할 수 있습니다
- 💬 댓글 기능 - Giscus를 통한 GitHub 기반 댓글 시스템이 통합되어 있습니다
- ✏️ 마크다운 에디터 - Toast UI Editor를 사용해 게시글 작성 가능(Back-end 사용시 업로드 가능, 미완성)
- 🖼️ 이미지 업로드 - 블로그 포스트에 이미지를 쉽게 추가할 수 있습니다 (Back-end 사용시 업로드 가능, 미완성)

## 컨텐츠 작성

### 블로그 포스트 추가

`article` 디렉토리에 `.mdx` 파일을 생성하여 블로그 포스트를 추가할 수 있습니다. 각 파일은 다음과 frontmatter 형식을 포함해야 합니다:

```mdx
---
title: '포스트 제목'
description: '포스트 설명'
icon: ''
image: ''
tags:
  - 'tag1'
  - 'tag2'
draft: false
date: 2023-10-14 12:56:15
series: 'series-name'
---

마크다운 콘텐츠
```

### 에디터 사용

개발 서버를 실행한 후 `/write` 경로에 접속하여 Toast UI 에디터를 사용할 수 있습니다.
(텍스트 입력만 가능, 미완성)

## 기술 스택

- Next.js 13
- React 18
- MDX
- Tailwind CSS
- Giscus
- Toast UI Editor
